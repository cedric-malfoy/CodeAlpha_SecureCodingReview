# CodeAlpha Secure Coding Review

Task 3: a code review of a deliberately vulnerable Python/Flask notes application, with a corrected implementation and reproducible evidence.

The `vulnerable` package is an intentionally insecure educational baseline. Run it only on localhost with fictional data. No public deployment is part of this project.

The baseline is recorded first so all later audit findings can refer to an immutable source commit. The complete review, corrected version, and verification evidence follow in subsequent commits.
